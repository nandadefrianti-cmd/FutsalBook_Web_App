# ⚽ Futsal Field Booking System

A full-stack web application designed for futsal venue owners and players to manage court schedules, online bookings, and revenue reports efficiently. Built as the final project for **IK301 (Advanced Database Systems)** and **IK102 (Software Engineering Fundamentals)**.

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **DevOps / Containerization:** Docker, Docker Compose

---
